# 페이지 공방

물음에 하나씩 답하면 내 웹 페이지가 생기는 앱입니다. 아이도 어르신도 쓸 수 있게 그림 카드로 묻고, 말로 적기 · 사진 찍기를 돕습니다.
다 만든 뒤에는 미리보기에서 고칠 곳을 눌러 글 · 사진 · 배경 · 순서를 고치고, 디자인(분위기 · 색상 · 글씨체)을 바꿀 수 있습니다.
브라우저로 열고 «홈 화면에 추가»하면 앱처럼 쓸 수 있고, 만든 페이지는 그 기기 안에만 저장됩니다(서버로 보내지 않음).
저장하면 인터넷 없이도 열리는 웹 페이지 파일 하나가 됩니다.
