# 페이지 공방

무엇을 만들지부터 순서대로 안내받으며(종류 → 이름 → 형태 → 디자인 → 기능 → 내용 → 확인) 세련된 웹 페이지를 만드는 설치형 웹 앱입니다.
다 만든 뒤에는 블록 편집기에서 순서를 끌어 바꾸고 칸마다 자세히 고칠 수 있습니다.
브라우저로 열고 «홈 화면에 추가»하면 앱처럼 쓸 수 있고, 만든 페이지는 그 기기 안에만 저장됩니다(서버로 보내지 않음).
내보내기는 바깥 요청이 없는 HTML 한 장(파일 저장 · 코드 복사)입니다.
